# A&A Travel Solutions — Free One-Page Website

## 1. Set your Instagram and WhatsApp links

Open `script.js` and edit:

```js
const CONFIG = {
  instagramUsername: "YOUR_INSTAGRAM_USERNAME",
  whatsappNumber: "@aadhil.cmb",
  whatsappMessage: "Hello A&A Travel Solutions! I would like to plan a trip."
};
```

- Instagram: username only, without `@`
- WhatsApp: full international number, without `+`, spaces or brackets.
- You can also change the pre-filled WhatsApp message.

## 2. Free publishing — GitHub Pages

1. Create a free account at GitHub.
2. Create a new **public repository**, e.g. `aa-travel-solutions`.
3. Upload **all files and folders** from this package. Keep the `assets` folder.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then Save.
7. GitHub will give you a free `github.io` website address.

You can later connect a custom domain if you purchase one.

## Files

- `index.html` — page structure/content
- `styles.css` — modern responsive design
- `script.js` — social links + interactions
- `assets/aa-travel-solutions-logo.jpg` — your supplied logo

No database or server is required.
